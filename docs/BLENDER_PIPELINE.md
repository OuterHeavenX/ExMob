# EXMOB - BLENDER PIPELINE

Blender is the primary 3D asset-production tool. Source lives in `blender/`; exported runtime
assets live in `assets/models/`. They are never mixed.

## Current state (v0.1.0)

The initial library is **generated by Python scripts** (`blender/tools/`) that build parametric
low-poly prototype meshes with correct naming, scale, origins, and materials, then export GLB.
This proves the pipeline end to end (Blender -> GLB -> runtime loader) and produces consistent
blockout assets. Every generated asset is a **prototype**, not production art. See STATUS.md.

Characters are exported as a hierarchy of named parts (`Head`, `Torso`, `ArmL`, `ArmR`, `LegL`,
`LegR`, `SOCK_Hand_R` weapon socket) so the runtime can drive simple procedural animation until real
rigs and skeletal animation land.

One asset family per `.blend`. Never one monolithic file.

## Naming standard

| Prefix | Type | Example |
| --- | --- | --- |
| CHR_ | Character | `CHR_ExMob_Body`, `CHR_Goon01_Body` |
| WPN_ | Weapon | `WPN_Pistol01`, `WPN_Shotgun01` |
| ENV_ | Architecture / environment | `ENV_Cabin_Wall_A`, `ENV_Cabin_Window_A`, `ENV_Tree_Pine_A` |
| PRP_ | Prop / furniture | `PRP_Couch_A`, `PRP_Lamp_Floor_A` |
| VEH_ | Vehicle | `VEH_Sedan_A` |
| MAT_ | Material | `MAT_Wood_Cabin`, `MAT_Cloth_Coat` |
| TEX_ | Texture | `TEX_WoodCabin_BaseColor`, `TEX_WoodCabin_Normal` |
| ANM_ | Animation action | `ANM_ExMob_Run`, `ANM_Goon_Death_A` |
| COL_ | Collision mesh (not rendered) | `COL_Couch_A` |
| SOCK_ | Socket empty | `SOCK_Hand_R`, `SOCK_Muzzle` |

Variants use `_A`, `_B`, `_C`. Damaged variants use `_Broken`: `ENV_Cabin_Door_A_Broken`.
LODs use `_LOD0`, `_LOD1`, `_LOD2`.

## Scale and orientation

- 1 Blender unit = 1 meter. Ray is 1.85 m tall.
- Forward is **-Y** in Blender, which the glTF exporter converts to **+Z forward, +Y up** in the
  runtime. Characters face -Y in Blender.
- Origins: characters and props at the base center (feet on the floor). Doors at the hinge.
  Windows at the sill center. Wall modules at the bottom-left corner of the module.
- Apply all transforms before export.

## Modularity (architecture)

Wall modules are 1 m wide, 2.8 m tall, 0.2 m thick. Windows and doors are wall modules with
openings. Corners are dedicated modules. Floors are 1 m tiles or a single quad per room.

## Materials

Principled BSDF only. PBR metal/rough workflow. Texture sets: BaseColor, Normal, ORM (occlusion,
roughness, metallic packed). Shared materials across assets wherever possible (one cabin wood, one
metal, one fabric). Texture sizes per PERFORMANCE_BUDGET.md. No 4K by default.

## LODs

LOD0 for hero assets viewed close (Ray, weapons in hand). LOD1 for enemies and furniture. LOD2 for
trees and rocks (instanced). The runtime picks by distance; generated prototypes currently ship a
single LOD.

## Rigging and animation (target)

- Humanoid rig with a shared skeleton across all characters so animations retarget.
- Required ExMob actions: Idle, Walk, Run, Aim, Fire_Pistol, Reload_Pistol, Fire_Shotgun,
  Reload_Shotgun, Hit, Death, Dodge (optional).
- Required enemy actions: Idle, Walk, Run, Aim, Fire, Reload, Hit, Death, Breach_Door,
  Window_Entry.
- Export animations in the character GLB as named clips (`ANM_*`).
- Root motion off; movement is driven by gameplay.

## Export (GLB)

- Format: glTF Binary (.glb), +Y up.
- Include: selected objects only, apply modifiers, normals, UVs, vertex colors if used.
- Materials: export with textures packed. Use WebP/JPEG for color, PNG for normal/ORM.
- Compression: Draco or meshopt via the runtime tooling step (`npm run blender:build` runs
  gltf-transform if installed; not yet enabled). See GRAPHICS_TECHNOLOGY.md.
- Output to `blender/exports/`, then copied to `assets/models/<category>/`.

## Generator scripts

`blender/tools/exmob_lib.py` holds shared helpers (materials, naming, export).
`blender/tools/build_*.py` build each family. `tools/build-blender-assets.mjs` runs Blender
headless (`blender -b -P`) and copies output into `assets/models/`.

```bash
npm run blender:build
```

Requires Blender on PATH or `BLENDER_PATH` set.
